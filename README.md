
# XO Game (Tic Tac Toe) - Java Console App

Bu layihə Java proqramlaşdırma dili ilə yazılmış konsol əsaslı iki nəfərlik `XO` (Tic Tac Toe) oyunudur. İstifadəçilər qeydiyyatdan keçir, oyuna başlayır, qalib təyin olunur və qaliblərin siyahısı yadda saxlanılır (scoreboard).

## ✨ Xüsusiyyətlər

- ✅ İstifadəçi adı və parol ilə daxilolma
- 👤 İki oyunçulu oyun sistemi
- 🧠 Oyun loqikası: X və O daxil etmə, boş hücrə yoxlaması
- 🏆 Qalibin təyini və heç-heçə vəziyyəti
- 🔁 Menü ilə idarəetmə (Ad dəyişmək, Oyuna başlamaq, Çıxmaq)

## 🚀 Necə işə salınır?

### 1. Klonlayın:

```bash
git clonehttps://github.com/alimrzd04/Game-XO.git
cd GameXO
```
### 2. Compile edin:
```javac GameXO.java```
### 3. Run edin:
```java GameXO```

## 🕹️ Oyun qaydaları

-   Oyun sahəsi 3x3-lük kvadratdan ibarətdir.
    
-   İki oyunçu növbə ilə X və O daxil edir.
    
-   Hansı oyunçu 3 simvolu yan-yana, üst-üstə və ya diaqonal yerləşdirərsə,       qalib olur.
    
-   Bütün hüceyrələr dolduqda və qalib yoxdursa — heç-heçə olur.
